# 站主工作台

工作台支持配置后的在线入口，并保留 SSH 维护方式。默认只接受本机或已验证的 HTTPS 代理；只有站主明确选择并设置允许标志后才接受公网 HTTP。入口路径为 `/_owner`，不出现在主导航中；密码和会话校验才是授权依据。

## 首次设置站主密码

部署后，在服务器 root 终端运行：

```bash
runuser -u easeblog -- env BLOG_EDITOR_DIR=/var/lib/ease2k-blog/editor node /opt/ease2k-blog/current/setup-owner.mjs
```

按终端提示输入两次密码，至少 12 位。输入不会显示，不要将密码发到聊天、写进命令参数或提交到仓库。服务器仅保存加盐哈希。

重置密码时，在同一命令最后添加 `--reset`。旧会话会立即失效，文章不受影响。

## 打开工作台

配置在线代理后，点击网站页脚昵称即可在新标签页进入在线后台，输入站主密码即可编辑；日常使用无需本机 SSH 隧道。登录页可选记住设备 30 天。

SSH 仍可作为备用维护方式。在自己的电脑建立 SSH 隧道，替换服务器地址和私钥路径：

```bash
ssh -i /path/to/ssh_private_key -N -L 3000:127.0.0.1:3000 root@YOUR_SERVER_IP
```

保持该终端窗口运行，浏览器打开 http://localhost:3000/_owner，输入站主密码。

## 编辑和发布

- 点击“新建文章”，填写标题、摘要、标签和 Markdown 正文。
- 为文章添加 `Java`、`MySQL`、`HTML`、`CSS` 或 `JavaScript` 标签即可进入对应主题分区，支持大小写变体，`JS` 也归入 JavaScript。同一篇文章可以属于多个主题；首页只展示有文章的分区。
- 常用标签随网站语言自动切换，例如“日常 / Daily life”“生活 / Life”“学习笔记 / Study notes”；填写对应的中文或英文均可。技术名称和未收录的自定义标签保留原文，站主填写的标签不会被改写。
- “保存草稿”仅保存到站主空间；“发布文章”会让内容出现在公开网站中，访客刷新即可看到，无需重新打包。
- 已发布文章可“保存并更新”，或“撤下并存为草稿”。
- 发布时间在首次点击“发布文章”时由服务器自动记录，按北京时间显示到分钟，无需手动选择。保存草稿不会确定发布时间，后续编辑、撤下或恢复后重新发布保留首次发布时间。英文正文可以暂留空。
- “修改记录”保留最近 30 个版本；载入历史内容后，需要再次保存才会生效。
- 删除会进入“回收站”，恢复时先变为草稿，需要确认后重新发布。
- 多窗口修改同一篇文章时，版本不匹配会拒绝保存，避免覆盖另一窗口的更新。
- 有未保存修改时，离开页面或切换文章会提示确认。建议定期保存草稿。

## 数据与备份

服务器的在线数据保存在 `/var/lib/ease2k-blog/editor/`：

- `content.sqlite` 及其 WAL 文件：在线文章、草稿、版本记录和会话。
- `owner.json`：站主密码哈希与会话密钥。

安装脚本仅更新 release 代码，不覆盖上述文件。旧版 `/var/lib/ease2k-blog` 中的数据库和认证文件不自动迁移。

工作台的“导出备份”会下载当前文章和回收站的 JSON 数据，包含草稿。请保存到私人备份位置，不要直接提交到公开仓库。需要完整恢复（包含修改记录）时，应在服务停止期间备份整个编辑数据目录，或使用 SQLite 在线备份工具。

随包文章作为初始数据。在线修改同一 ID 后优先使用在线版本；在线删除会保留删除标记，避免下次部署重新出现。在线文章不会自动同步到 GitHub。

撤下文章会从当前公开网站中隐藏它；已存在于公开源码、历史记录或其他人的副本中的内容不会因此消失。

## 开发与测试

本机先运行 `npm run build`、`npm run owner:setup`，再运行 `npm start`；默认数据目录为 `self-hosted/data/editor/`，已被 Git 忽略。也可以使用 `npm run dev`，通过终端输出地址下的 `/_owner` 访问。

```bash
npm run check
npm run build
npm test
npm run test:owner
npm run test:nginx
```

公网登录需要明确配置 HTTPS 来源和受信代理密钥；默认继续拒绝转发请求，不能仅删除 Nginx 的拒绝规则。

## 自动保存与图片

编辑后约 1.2 秒自动保存到独立的编辑草稿，同时在当前浏览器保留恢复副本。重新登录或刷新后，可以从左侧“可恢复的编辑草稿”继续。已发布文章的编辑草稿不会直接对外公开；仍需点击“保存并更新文章”。多窗口同时保存同一编辑草稿会检测冲突，不自动覆盖。

摘要留空时会从正文提取；阅读时长自动估算。标签支持多个技术主题，文章底部提供前后篇及同主题内容。

正文支持“添加图片”、粘贴截图和拖入文件。当前支持 PNG、JPEG、WebP、AVIF 静态图片，原文件不超过 20 MiB；浏览器将最长边缩到 1920 像素，去除原文件元数据并转换为 WebP。单张压缩后不超过 3 MiB，每次最多 6 张。上传成功后可修改 Markdown 中的“图片说明”。

图片保存在编辑数据目录的 `media/` 中。草稿预览通过已登录的站主接口读取；只有已发布文章引用的图片才允许从公开地址读取。撤下文章后，若没有其他已发布文章引用该图片，新的公开请求会返回 404；曾经公开的图片可能已被其他人保存。

自动备份、校验和恢复方法见 [备份说明](BACKUP.md)。JSON 导出包含文章与编辑草稿，但不嵌入图片文件；完整恢复请使用服务器备份。

## 系列文章与在线示例

展开“系列文章（可选）”，选择已有系列或新建系列。填写标题、介绍及章节顺序，数字越小越靠前。系列地址自动生成，也可改为小写字母、数字和短横线。英文介绍可以留空。每篇文章最多加入一个系列，同一系列使用相同地址；公开专栏只显示已发布且有正文的文章，介绍取排序最前的公开章节。入口为 `/series`，目录可直达各章，文章页的前后篇按系列顺序排列。

展开“在线前端示例（可选）”并勾选附加示例，即可编辑 HTML、CSS、JavaScript。示例代码和普通正文一起自动保存到编辑草稿，点击发布后才会公开。每篇文章可附加一个示例；读者修改的是本页副本，不会改写原文章。点击“运行”查看效果，“停止”清除运行结果，“重置”恢复最初代码。控制台显示 console 输出及运行错误。

示例使用独立 iframe，仅在点击运行后执行，不提供外部库或网络资源加载，不允许读取父页面、站主会话或浏览器存储。只支持浏览器原生前端代码，不执行 C++、Java 或 SQL。

## 代码块阅读

普通 Markdown 代码围栏会按所标语言高亮，常用语言包含 C/C++、Java、JavaScript、TypeScript、HTML、CSS、SQL、JSON、Bash。无法识别的语言保留纯文本。行号可以按需打开；超过 24 行的代码默认显示前 12 行，展开后显示全部。复制按钮始终复制原始完整代码，不包含行号或高亮标记。

在围栏语言后添加 `{2,4-6}` 可以强调第 2、4、5、6 行，例如：

````markdown
```cpp {2,4-6}
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello" << endl;
}
```
````


## 专栏与图片库

工作台上方的“专栏”统一维护中英文标题、介绍、封面和章节顺序。可以拖动章节，也可以用上下按钮。专栏地址创建后保持不变；没有已发布章节的专栏不会出现在公网。文章编辑器只负责选择所属专栏，介绍和顺序以专栏管理为准。

“图片库”显示尺寸、大小和引用位置。上传或重命名后可以在不同文章中复用；图片名称离开输入框后自动保存。封面也从图片库选择。替换图片会更新当前文章、编辑草稿和专栏封面的引用，保留原图片与历史版本，并增加文章修订号；请先提交当前编辑，再执行替换。

未引用的图片可以移入回收区并恢复。文章回收站、编辑草稿与历史版本中的引用也会保护图片。回收区为逻辑删除，暂不永久清理文件，因此不会释放磁盘空间。公网只允许读取正在被已发布文章或公开专栏封面引用的图片。

“导出文章 JSON”包含文章、草稿、专栏和图片元信息，不包含图片文件与站主凭据。完整备份与恢复见 [BACKUP.md](BACKUP.md)。

## 搜索与订阅

搜索结果显示命中摘要并突出关键词；进入文章后可定位和切换匹配位置，命中的折叠代码会自动展开。公开 RSS 地址是 `/feed.xml`（全部）、`/feed/technical.xml`（技术）和 `/feed/series/专栏地址.xml`（单个专栏）；订阅入口在页脚，汇总页是 `/subscribe`。所有订阅只包含正式公开内容。


## 本机中英文翻译

在文章正文旁点击“中英翻译”，或展开“中英文自动翻译”。使用桌面版 Chrome，通过 HTTPS 在线入口或 `localhost` 的 SSH 隧道入口登录。选择“中文 → 英文”或“英文 → 中文”，点击“生成译文预览”；首次使用可能需要下载语言包，下载期间可取消。

翻译在 Chrome 本机运行，无需配置翻译 API 密钥。标题、摘要和正文会一起处理；Markdown 中的代码（包括中文注释）、公式、图片、链接地址与引用定义保持原样。长正文分段处理，界面显示进度。Markdown 特殊字符会转义，模型改变格式标记时回退为安全分段翻译。

生成结果先留在可编辑预览中，可“查看排版”、修改或丢弃；点击“应用到编辑草稿”后，目标语言内容才会被替换并进入原有的私有自动保存流程。检查后再保存或发布，访客切换语言即可读取已保存译文。原文或目标内容在预览期间改变时，旧预览不能直接应用，需要重新生成。翻译可能有术语或语序错误，请校对后发布。

不支持本机翻译的浏览器会显示说明，不会把文章交给其他翻译服务。手机端暂不提供生成能力，但仍可阅读已经保存的双语文章。


## 页脚入口与记住设备

网站页脚的昵称是站主入口，保持普通署名样式，支持点击、触屏和键盘访问。选择 HTTPS 模式时，HTTP 入口会跳转至 HTTPS；明确启用 HTTP 模式时直接打开在线后台。

普通登录有效期为 8 小时。自行勾选“记住这台设备（30 天）”后，同一浏览器可以保持登录 30 天，不保存明文密码。退出登录会立即撤销当前会话；重置站主密码会让全部旧会话失效。清除浏览器 Cookie、更换设备或超过有效期后需重新登录。

## 配置公网 HTTPS（可选）

先安装新版本部署包。只有站主明确同意 [Let’s Encrypt 用户协议](https://letsencrypt.org/repository/) 后，才在包目录以 root 运行：

```bash
bash issue-owner-certificate.sh YOUR_PUBLIC_IPV4 --accept-terms
```

该脚本申请免费的 IP 地址证书（需要 Certbot 5.4+），通过现有 80 端口完成验证，在 443 端口提供 HTTPS，并配置每 12 小时检查自动续期。云服务器安全组需允许 HTTPS 443 端口。IP 证书有效期约 6 天，不能关闭续期任务。证书申请需要向签发机构提供公网 IP，证书会进入公开透明日志。

配置会备份到 `/var/backups/ease2k-owner-https.*`。密码哈希和文章数据保持原样。服务器仍仅监听本机 3000；Nginx 通过独立代理密钥及固定 HTTPS 来源访问后台，公共只读接口继续过滤凭据。代理密钥保存在 root 可读的 `/etc/ease2k-blog/owner-https.env` 和 Nginx 配置中，不得提交源码或显示在日志里。HTTPS 使用 `Secure`、`HttpOnly`、`SameSite=Strict` 和 `__Host-` Cookie；保留原有 CSRF、密码尝试限制及 SSH 维护入口。

验证：`npm run test:owner-https` 使用临时测试证书和真实 Nginx，检查代理伪造、Cookie、会话有效期、退出撤销、私密内容隔离和 SSH 兼容，不需要真实站主密码。


## 明确选择公网 HTTP

HTTP 不加密传输，站主密码、登录 Cookie 和文章内容可能被网络中间方读取或篡改；隐蔽入口不能代替传输加密。Chrome 本机翻译在公网 HTTP 中不可用。只有站主已明确接受这些限制后，才运行：

```bash
bash configure-owner-http.sh YOUR_PUBLIC_IPV4 --allow-plaintext-login
```

该模式设置 `BLOG_OWNER_ALLOW_HTTP=1`、固定 HTTP 来源和独立代理密钥，保留密码校验、登录尝试限制、CSRF、私有草稿隔离、8 小时或可选 30 天会话。未设置允许标志时，即使代理来源配置为 HTTP 也会被拒绝。登录页会显示未加密连接提示。浏览器在 HTTP 下缺少 `crypto.randomUUID` 时使用 `crypto.getRandomValues` 生成 UUID，支持新建文章和专栏。

配置会备份至 `/var/backups/ease2k-owner-http.*`；旧 HTTPS 入口和证书续期任务停用，现有证书文件保留。证书代理环境文件仍为 `/etc/ease2k-blog/owner-https.env`，其文件名不决定访问协议。测试使用 `npm run test:owner-http`。
